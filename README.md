# 跨 ±180° 经线禁区编辑台

一个**不依赖任何在线地图瓦片**的 React + TypeScript SVG 编辑台：输入一个凸禁区和一条航路，
精确判定航路在禁区内的参数区间、进入/离开见证，并在日界线处分段绘制。
Chart 页面由 Docker Compose 运行（nginx 托管纯静态构建产物）。

## 运行

```bash
# 开发
npm install
npm run dev

# 测试
npm test

# Docker Compose（chart 页面）
docker compose up --build
# 打开 http://localhost:8080
```

## 输入约定

- 坐标以**整数百万分之一度**（bigint，1° = 1_000_000）存储；纬度 ±80°、经度 ±540°。
- 禁区 3～20 顶点；航路 2～80 点。
- 禁区非凸、自交（叉积符号不一致）、零长边、不闭合、全共线直接拒绝。
- **短弧展开**：相邻经度总是取与前一点相差不超过 180° 的世界副本；恰好相差 180° 的边视为歧义并拒绝。
- 禁区还要检查闭合边：末点沿短弧必须落回首点所在副本（差值为 0，180° 同样歧义拒绝）。
- 航路段与禁区边均按**展开后的经纬平面直线**解释。

## 判定算法（`src/geometry/`）

1. `unwrap.ts` — 经度规范化 `(-180,180]`、短弧展开（bigint floor 除）。
2. `clip.ts`
   - 凸性：统一为逆时针（CCW）后，对每条边用半平面 `cross(edge, P − v) ≥ 0`（**边界计入**）。
   - 每段航路按包围盒检查**必要的世界副本** `k`（仅可能相交的 `zone + k·360°`）。
   - 方向判定全部是 **bigint 整数叉积**；Liang–Barsky 的交参数用**约分分数** `Frac`（交叉相乘比较），
     区间初值 0/1，穿入边收紧下界、穿出边收紧上界。
   - 段内区间先合并，再用全局参数 `t = 段号 + 段内参数` 跨段合并（相邻区间相接即合并）。
   - 顶点擦过多条边时，同一边界参数上取**较小边号**作为见证。
3. `render.ts`
   - 航路/片段在奇数倍 ±180° 经线处切开；每一小段按其中点所在世界副本平移到画面条带，
     端点恰在 180° 时按行进方向吸附到左/右图缘——跨线几何不会横贯整张世界图。
   - 禁区填充与边对 `k=-1,0,1` 副本做矩形裁剪（Sutherland–Hodgman / Cohen–Sutherland），
     图缘描边去重。
4. **画面与区间表同源**：表格的每一行和图上绿色高亮都来自 `analyzeRoute` 返回的同一个
   `pieces[i]`（被截航路点列），点击表格行即高亮同一被截航路。

## 见证与区间表

- 每行给出合并后的全局参数区间 `[t进, t离]`（整数部分为航路段号）。
- 进入/离开见证给出展开平面经纬度（分数精度）与命中的边号；区间起点即航路起点时标注“航路起点”。
- 顶点擦过产生零长度（单点）区间，`pieces` 只含该见证点。

## 示例与测试覆盖

内置示例：跨日界线、顶点擦过、沿边行走（含共线顶点）、顶点压 180°、绕整圈。

`test/geometry.test.ts`（32 例）覆盖：

- 经度等价表示（190° 与 -170°、±540 输入、规范化到 `(-180,180]`）；
- 非凸 / 自交蝴蝶结 / 共线退化 / 180° 歧义边拒绝；
- 顶点擦过（零长度区间）、沿边行走（无见证）、角点进入；
- 跨线禁区与其等价经度表示给出相同分数区间；绕整圈闭合环、世界副本平移；
- 日界线分段：切两段、图缘吸附方向、禁区填充左右两块、图缘竖边不重复描边。
